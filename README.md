# 57Dentcare Landing Page

A responsive dental clinic landing page, built as my Week 1 task for Advanced Web Development.

## Built With
- HTML
- CSS
- Tailwind CSS v4
- Vite

## Features
- Mobile-first responsive design (starts at 360px)
- Navbar with a mobile menu that works without JavaScript
- Hero section with feature cards
- Treatments grid
- About Us and Why Choose Us sections
- Testimonials section
- Free consultation form
- Footer with newsletter signup and social links

## How to Run
1. Clone this repository
2. Run: npm install
3. Run: npx vite
4. Open the localhost link shown in the terminal
